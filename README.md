# 🐝 АпиКонтракт — Геоинформационная платформа контрактного опыления и координации кочевых пасек в АПК

**«АпиКонтракт»** — веб-приложение класса AgTech для решения двух взаимосвязанных проблем современного агропромышленного комплекса (АПК): **недобора урожая энтомофильных культур из-за нехватки опылителей** и **гибели кочевых пасек от сноса пестицидов**.

---

## 1. Актуальность проблемы в АПК

1. **Потери урожая от недоопыления (20–42%):** На энтомофильных культурах (подсолнечник, рапс, гречиха, горчица, эспарцет, плодовые сады) отсутствие управляемого подвоза пчёл приводит к пустозёрности и резкому снижению сборов.
2. **Хаотичная логистика кочевого пчеловодства:** Пасечники выставляют передвижные прицепы «вслепую» — в одном массиве возникает перегрузка и конкуренция за нектар, а соседние поля стоят без опыления.
3. **Почему государственный портал `bee-saturn.ru` (ФГИС «Сатурн») не решает задачу полностью:**
   - Госреестр работает как односторонняя витрина плановых химобработок и **не содержит координат кочевых пасек** на карте.
   - Портал не рассчитывает ветровой снос аэрозольного облака (индекс $\Delta T$ и азимут ветра).
   - В ФГИС «Сатурн» нет инструментов расчёта нормы пчелосемей на гектар, медового баланса поля и заключения контрактов на опыление.

**«АпиКонтракт»** использует слой плановых обработок ФГИС «Сатурн» в качестве контура безопасности (ФЗ-490 «О пчеловодстве», буфер $7\text{ км}$), объединяя агронома и пчеловода в едином интерактивном пространстве.

---

## 2. Основные модули веб-приложения

### 🗺️ Модуль 1. ГИС-Радар опыления и безопасности (Leaflet)
- **Слой полей:** полигоны участков с кадастровыми номерами, статусом «пестицидной тишины» и расчётом процента покрытия пчёлами.
- **Радиусы продуктивного лёта ($2.0\text{ км}$ и $3.5\text{ км}$):** автоматический пространственный пересчёт, сколько пчелосемей долетает до каждого поля (формула гаверсинуса) и нужно ли встречное опыление со второй стороны массива.
- **Слой ФГИС «Сатурн» ($7.0\text{ км}$ по ФЗ-490) + ветровой шлейф:** отображает карантинную зону вокруг обрабатываемого поля и векторный сектор сноса аэрозоля по реальному или моделируемому направлению ветра.
- **Интерактивная расстановка прицепов:** возможность поставить новую кочевую пасеку кликом по карте с мгновенной проверкой угроз и пересчётом покрытия.

### 🧮 Модуль 2. Двусторонний агроэкономический калькулятор («Выгода агронома ↔ Выгода пасечника»)
- Справочник норм опыления и нектаропродуктивности 6 основных энтомофильных культур РФ.
- **Для хозяйства:** расчёт требуемого количества семей ($N_{\text{рек}} = \lceil S \cdot k_{\text{культ}} \rceil$), прибавки урожая (т и ₽), затрат на контракт и чистого ROI.
- **Для пасеки:** расчёт биологического нектарного запаса поля ($S \cdot m_{\text{нектар}}$), выхода товарного мёда на улей, предупреждение о перегрузке кормовой базы и совокупного дохода (оплата опыления + мёд).

### 🌤️ Модуль 3. Агрометео и индекс $\Delta T$ (`Open-Meteo API`)
- Загрузка актуальной температуры, влажности, скорости и направления ветра для агрокластера (с резервной моделью для работы оффлайн).
- Расчёт психрометрического индекса **$\Delta T$** по аппроксимации Сталла для оценки испаряемости капель пестицидов и активности лёта пчёл.
- Интерактивный **симулятор ветра** для демонстрации изменения зоны сноса СЗР в реальном времени.

### 🤝 Модуль 4. Биржа заявок и Паспорт-договор кочёвки с QR-кодом
- Фильтрация полей по культуре, дефициту опылителей и статусу пестицидной безопасности.
- Генератор официального **Паспорта-договора кочёвки и опыления** с динамическим SVG QR-кодом, GPS-точкой разгрузки прицепа, окном ночного заезда (`22:00–04:00`), протоколом проверки ФГИС «Сатурн» и поддержкой печати (`window.print()`).

## 3. Структура проекта и стек технологий

Приложение построено на чистом модульном ES6+ стеке без тяжёлой сборки, что позволяет запускать его на любом статическом сервере или GitHub Pages:

- `index.html` — семантическая разметка SPA-панели с переключателем ролей (*Диспетчер АПК / Агроном / Пчеловод*).
- `css/styles.css` — адаптивный интерфейс AgTech-класса и `@media print` стили для печати Паспорта кочёвки.
- `js/data.js` — справочники энтомофильных культур (`CROPS_DB`), классы опасности СЗР (`PESTICIDE_CLASSES`), данные полей, пасек и обработок ФГИС «Сатурн».
- `js/map.js` — контроллер Leaflet-карты, гаверсинус-расстояния, расчёт покрытия и полигона ветрового шлейфа.
- `js/calculator.js` — экономическая модель Win-Win, расчёт индекса $\Delta T$ и клиент `Open-Meteo`.
- `js/app.js` — состояние приложения, биржа контрактов и генератор печатного Паспорта с SVG QR-кодом.

## 4. Локальный запуск

Поскольку проект использует нативные ES-модули (`type="module"`), запускайте его через любой локальный HTTP-сервер:

```bash
# Через Python 3
python -m http.server 8090
```

После этого откройте в браузере: `http://localhost:8090`
